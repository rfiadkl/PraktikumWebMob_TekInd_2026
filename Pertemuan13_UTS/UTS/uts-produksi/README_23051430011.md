## Deskripsi Project

Project ini merupakan aplikasi berbasis React.js yang digunakan untuk mengelola laporan produksi harian pada lingkungan industri manufaktur. Aplikasi memiliki fitur dashboard KPI produksi, input laporan produksi, riwayat data produksi, perhitungan netto dan yield otomatis, penyimpanan data menggunakan LocalStorage, serta fitur hapus data dan hapus semua data.

---

## Teknologi yang Digunakan

- React.js
- React Router DOM
- Bootstrap 5
- LocalStorage Browser
- Vite

---

## Cara Menjalankan Project

Untuk menjalankan project ini,

- 1.pertama buka terminal pada folder project lalu install seluruh dependency menggunakan perintah `npm install`.

- 2.Setelah seluruh dependency berhasil diinstall, jalankan project menggunakan perintah `npm run dev`.

- 3.Setelah server Vite berjalan, buka browser dan akses alamat `http://localhost:5173` untuk melihat aplikasi berjalan.

---

## Struktur Halaman

- `/` → Dashboard Produksi
- `/input` → Input Laporan Produksi
- `/riwayat` → Riwayat Data Produksi

---

## Fitur Utama

- Dashboard KPI Produksi
- Input laporan produksi harian
- Perhitungan netto dan yield otomatis
- Riwayat data produksi

- Hapus semua data

---

## Penyimpanan Data

Data disimpan menggunakan LocalStorage browser sehingga data tetap tersimpan walaupun browser direfresh atau ditutup.
